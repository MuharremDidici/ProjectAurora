AURORA BAĞIMSIZ KURTARMA REHBERİ (OFFLINE)

Windows 11 Görev Çubuğunu Geri Yükleme

Project Aurora hiçbir zaman Windows Explorer (explorer.exe) işlemini değiştirmez, sonlandırmaz veya belgelenmemiş kayıt defteri ayarlarına müdahale etmez. Aurora kapalı veya kaldırılmış olsa bile aşağıdaki adımlarla Windows görev çubuğunuzu saniyeler içinde kalıcı görünür hale getirebilirsiniz.

Windows Görev Çubuğu Ayarlarını Aç

Adım 1 — Windows Görev Çubuğu Ayarlarını Açın

  1. Klavyeden Win + I tuşlarına basarak Ayarlar uygulamasını açın (veya Win + R tuşlarına basıp ms-settings:taskbar yazarak Enter'a basın).
  2. Kişiselleştirme → Görev Çubuğu → Görev çubuğu davranışları bölümünü genişletin.
  3. Görev çubuğunu otomatik olarak gizle (Automatically hide the taskbar) seçeneğinin işaretini kaldırın.

Adım 2 — Aurora Güvenli Mod veya Temiz Kaldırma

  • Güvenli Modda Başlatma: Komut satırından Aurora.App.exe --safe-mode çalıştırarak varsayılan kurtarma temasıyla ve minimum modüllerle açabilirsiniz.
  • Başlangıçtan Kaldırma: Ctrl + Shift + Esc ile Görev Yöneticisi'ni açıp Başlangıç uygulamaları sekmesinden Project Aurora öğesini devre dışı bırakabilirsiniz.
  • Kullanıcı Verileri Konumu: Tüm yerel veriler yalnızca %LOCALAPPDATA%\ProjectAurora klasöründedir.
