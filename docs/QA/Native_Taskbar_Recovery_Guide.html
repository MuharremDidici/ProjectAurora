AURORA BAĞIMSIZ KURTARMA REHBERİ (OFFLINE)

Windows 11 Görev Çubuğunu Geri Yükleme

Project Aurora (aurora.exe) hiçbir zaman Windows Explorer (explorer.exe) işlemini değiştirmez veya sonlandırmaz; dahili Watchdog süreci beklenmedik bir çıkışta görev çubuğunu <100 ms içinde otomatik geri getirir. Aurora kapalı olsa bile aşağıdaki adımları kullanabilirsiniz.

Windows Görev Çubuğu Ayarlarını Aç

Adım 1 — Tek Komutla Geri Yükleme veya Windows Ayarları

  1. Komut satırında aurora.exe --restore-taskbar (veya Restore-Windows-Taskbar.cmd) çalıştırın.
  2. Alternatif olarak Win + R ile ms-settings:taskbar açıp Görev çubuğunu otomatik olarak gizle seçeneğini kapatın.

Adım 2 — Aurora Güvenli Mod & Temiz Kaldırma

  • Güvenli Modda Başlatma: aurora.exe --safe-mode (veya Start-Aurora-SafeMode.cmd) özgün görev çubuğunu gizlemeden güvenli oturum açar.
  • Temiz Kaldırma: "%LOCALAPPDATA%\Programs\ProjectAurora\uninstall.exe" --uninstall veya Windows Yüklü Uygulamalar → Project Aurora.
  • Kullanıcı Verileri Konumu: Tüm yerel veriler ve günlükler %LOCALAPPDATA%\ProjectAurora altındadır.
